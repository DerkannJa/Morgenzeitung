# Morgenzeitung

Personalisierte Morgenzeitung als EPUB für den Kindle: Wetter, Termine und Feiertage aus Home Assistant plus Nachrichten aus RSS-Feeds, täglich 05:30 Uhr per Send-to-Kindle.

- **Einrichtung:** [ANLEITUNG.md](ANLEITUNG.md)
- **Stand, Architektur, offene Punkte:** [HANDOFF.md](HANDOFF.md) – vor jeder Weiterarbeit lesen
- **Konfiguration:** `config.toml` (im Repo nur Platzhalter für Zugangsdaten)
- **Test ohne Server:** `python3 tests/mock_lauf.py`
